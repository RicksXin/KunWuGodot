# 本地美术制作工作区

`art/` 只用于本机的美术制作、候选、来源归档和评审，不随主 Godot 仓库提交。
主仓库中的正式运行素材只放在 `assets/`；只有经过用户视觉确认的素材才能从这里晋升过去。

约定：

- `source_archive/`：生成原图、迁移源文件和来源记录。
- `candidates/`：需求板、待审候选及确定性编译中间产物。
- `review/`：联系表、截图和视觉评审产物。
- 根目录下的母图：仅作为本地生产输入，不是远端运行依赖。
- 运行场景、脚本和正式 Resource 不得引用 `res://art/`；制作与验证工具可以引用本地文件。
- 需要备份或多人协作时，应使用独立的私有美术仓库或受控存储，不要用 `git add -f` 加入主仓库。

Godot 会继续在本机看到该目录；Git 只保留本说明文件。清理 Git 索引不会删除本机素材，也不会自动
清除远端既有历史中的旧副本。
