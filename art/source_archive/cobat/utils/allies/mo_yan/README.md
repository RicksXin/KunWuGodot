# 墨言待机动画母版

- 来源：用户提供的 `/Users/zhangxiaoen/Downloads/image-2/` Meowa Godot 4 导出包。
- 原始图集：`mo_yan_idle_source_sheet.png`，`1472×1920`，4 列 × 3 行；前 10 格有效。
- 原始单帧：`368×640`，与运行时 `86×149` 宽高比近似，但背景为不透明白灰色。
- 原包中的 `.tscn` / `.tres` 不进入运行工程：其切帧是 10 帧、8 FPS，且场景显式使用线性过滤。
- 运行版由 `tools/compile_idle_portraits.py` 去除连通白灰背景、按整套共同边界等比缩放、固定脚底，
  并从 10 帧均匀取样为项目约定的 8 帧 `344×298` RGBA Sheet。

下载目录中的用户原文件不修改。本归档只作后续重新编译和视觉审计的稳定输入。
