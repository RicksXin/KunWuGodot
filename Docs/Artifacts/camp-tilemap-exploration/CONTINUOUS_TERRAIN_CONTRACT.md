# 连续台地组件契约（优先于旧独立岩壁美术方案）

状态：边界拓扑与样片行走已验证，连续直段美术仍阻塞；不宣称完整TileSet已交付。

## 规则

1. 内部同层相邻格只铺连续地面，不画崖沿/墙；墙只来自高低边界。
2. 角型按各高度层的占据轮廓识别；1邻接为凸角、3邻接为凹角，对角两块算两个独立凸角，不能变成桥。
3. 阶梯是单独边界接口，替换对应正墙，保留邻边；台阶碰撞和图像独立。
4. 原型保留128×64投影与48逻辑高差，22只是外侧展示底座。可见48、70、118落差必须拆为48层与22底座，不能纵向拉伸整图。
5. 美术需要连续地面、两朝向地面/覆土/岩壁一体边缘、内外角、阶梯接口。分层是渲染职责，不意味着这些过渡必须分别生图。
6. 已确认的L形母图保持原始440×300，锚点(220,64)。它是视觉参考和五格组件，不是可任意重复铺满的单格Tile。

## 实现与验证

scripts/prototypes/camp_boundary_plan.gd输入高度字典与阶梯连接；输出边集合、朝向、高低差、阶梯开口和分层角型，不输出图片推断的碰撞。
tools/validate_camp_boundary_plan.gd直接读取当前全营地运行高度，测试矩形/L形/洞/对角/窄道与4开口，结果boundary-plan.json。

全营地69段全部边界、45段可见正面边界，其中4段阶梯接口；12个分层凸角，当前完整营地层形状没有凹角（L形实验另验凹角）。通用模块应复用，而不是逐边生成45张。

边界规划器尚未替换旧实验的岩壁绘制；待连续素材验收后作为渲染输入接入，不在新美术缺失时恢复方块铺法。
