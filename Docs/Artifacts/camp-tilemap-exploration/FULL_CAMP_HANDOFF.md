# 全营地结构预览与美术交接

## 入口与边界
设置 → 营地 TileMap 实验 → 顶部下拉“全营地结构预览”。也可直接运行原场景并传入 `--fullcamp-preview`。
Godot编辑器打开 `scenes/prototypes/camp_terrain_sample.tscn`，F6后选择全营地。
这是已批准三层连接意图的12×12试排，不是最终布局视觉批准，不触发正式营地业务或写入存档。正式Map01不变。

## 已完成结构
- 格轴(64,32)/(-64,32)，高度96/48/0；保持局部小样每级48。旧概念80/40不用于本实现。
- 7座建筑，每座2×2逻辑占位；议事殿复用已批准图片，其余6座灰盒。门前站位独立于图像。
- 4道石阶：议事殿至左/右中层各一条，左右中层至下层各一条。任意一条关闭后仍可绕行到全部门口。
- 传送阵仅地面圈动效，溪流在地图外侧，仅定位与水流虚线占位，均可关闭动效；没有真实传送或水体玩法。
- 116个可走格；点击建筑走到门口，地面点选寻路，下方下拉目的地亦可导航。
- 灰盒/砌石/岩坡三种表面可切换；滚轮缩放、拖动平移、“总览”复位镜头。文字保持屏幕字号。局部与全景互切时恢复各自镜头。

## 关键文件
- `data/prototypes/camp_full_layout.json`：格子、建筑ID/占位/门、阶梯与出生点。
- `scripts/prototypes/camp_full_layout.gd`：实验场景表现、坡高插值、道路、命名挂点、点击与占位动效；复用局部小样移动实现。
- `scripts/prototypes/camp_terrain_sample.gd`：独立全景入口与工具栏。
- `tools/validate_camp_full_layout.gd`：全景验收，`--capture-fullcamp --fullcamp-preview`可输出实机图。
- `fullcamp-preview.png`：当前岩坡组合实机截图。

## 验证
Godot4.7.1导入、116格连通/28格建筑阻挡、7门口+传送阵连续行走、4道台阶中点高度、禁止侧穿与跳崖、逐一封阶的备用路线、三种表面反复切换、角色图层、动效关闭、场景互切通过。
原局部台地验证与16mask/10平面布局验证同时通过。测试使用 `--no-profile-write --ignore-config-cache`。
尚需视觉批准：全营地具体摆位、建筑比例、砌石/岩坡风格与溪流位置。自动检查不能替代批准。
