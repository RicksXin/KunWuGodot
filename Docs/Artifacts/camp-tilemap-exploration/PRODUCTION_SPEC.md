# 议事殿样板：首批试制规格

用户已批准整体示意图的连续山体与三层台地结构。此文规定第一块样板的试制参数；不把结构批准视作每张素材的视觉批准。

## 1. 试制范围

议事殿＋前院岩土地面＋石铺路＋一段连续崖壁＋一道下行石阶。先交付尺寸图、清单和提示词；本轮没有提交新素材生成。
已有原营地背景作风格参考，已确认示意图作结构参考，旧议事殿作造型参考；三者不能互相替代。

## 2. 尺寸与投影契约

| 项目 | 首批采用值 | 含义 |
|---|---|---|
| 游戏目标视口 | 817×375 | 横屏；总览图不等于该视口的1:1截图 |
| 相机基准 | 正交，俯角35°、平面旋转15° | 首批统一制作基准，最终视觉验收后再锁全营地 |
| 地面格距 | 48×48规划单位 | 是地面平面单位，不是投影后屏幕方格 |
| 高差 | 40规划单位 | 相邻台地高差；投影后垂直位移约32.77像素（倍率1时） |
| 上层样板地面 | 576×432＝12×9格 | 只裁取议事殿区域进行试制 |
| 建筑逻辑底面 | 192×144＝4×3格 | 起点(96,48,40)；替代结构草图的192×112临时值 |
| 建筑显示包围框 | 暂定256×192 | 包括屋顶与台基，不能用包围框当碰撞；原图247×165只是参照 |
| 道路 | 宽96＝2格 | X=144–240，Y=192–432，标高40 |
| 石阶 | 宽96、进深96、落差40 | 8级，每级进深12、升高5；Y=432–528 |
| 下层落脚区 | 至少96×48 | 石阶下口后留1格深平台 |
| 岩壁直段 | 长192、高40、窄顶进深12 | 接口尺寸固定，整体重复视觉靠变体打散 |

倍率1下，两条48单位网格边分别投影为约(46.36,7.13)和(-12.42,26.59)。不要直接把这些素材塞进48×48屏幕正方格。
实现阶段：地面格坐标共享同一投影，地面材质与投影网格匹配；建筑、崖壁、阶梯使用已投影视角图像，只投影锚点，不能再次剪切图像。原生TileMapLayer或网格渲染方式在切片验证时确定，本轮不改运行实现。
两种纹理母图采用正俯视是为了获取纯平面材质，不代表更改整个营地的斜俯视正交视角。

## 3. 生成与本地工作的分界

生成5个独立候选，见FIRST_BATCH.json和prompts/：C01岩土地面、C02石铺路、C03岩壁、C04石阶、C05议事殿视角校准。按顺序逐项提交，不一次生成5张合集。
C01/C02是材质来源，不承诺模型能生成严格无缝Tile。先验证纹理与建筑像素密度，再进行本地平铺处理；原生48单位格只作为逻辑尺度，不能把1024母图直接缩为48像素整张反复贴。
本地工作：选取合适纹理尺度、硬边/Alpha检查、接缝处理、直边/内外角/末端过渡模板、锚点与资源组装、接地与层级检查。若确定性边缘不能达到质量，再单独列缺失素材，不用模糊接缝掩盖问题。
这一轮不启用Dual Grid或风车母图；如后续选该笔刷方案，另按强制技能冻结掩码与母图契约，不把这两张材质图当作风车母图。

## 4. 图层和Marker

从后向前：基础岩土→道路/苔藓贴花→高差岩壁与阶梯→建筑台基/主体→可选前景→名称与状态Marker。
议事殿先沿用一个静态主体；首轮不新增复杂建筑动画。
Marker2D先定义门口(192,192,40)、阶梯上口(192,432,40)、下口(192,528,0)。名称和状态图标的偏移在实际图像接入后测量，不能从当前方块高度臆造。
事件/锁定图标复用assets/camp/ui/common/；标记节点不需生成图片，入口与碰撞不从背景反推。

## 5. 首批生产操作

参考图已整理至 `art/candidates/camp-orthographic-slice/references/`，SHA-256记录在FIRST_BATCH.json。
先用prompts/01_岩土地面.md：按其顺序上传风格图和结构图，复制完整提示词，生成1张，下载原始PNG。
默认按项目规范由用户在ChatGPT页面完成上传/提交/下载；代理负责可复核的输入和后处理。没有API Key或Meowa前置要求。
原图进入incoming/；修整图进入compiled/。全部属于候选，不修改assets/，不影响现有营地或Map01。

## 6. 验收

- 母图：图像可读、尺寸记录完整，独立模块需要真实Alpha，主体不裁切；仅透明留白不能说明部件已分层。
- 地形：3×3平铺、直路、L角、T口、尽头、台面内外角；在目标尺寸下看重复与接缝。
- 高差：崖壁不透底、阶梯两端齐平、实心侧壁接地；没有黑缝或悬空台地。
- 建筑：屋檐/台基轴线匹配投影，门前道路连续，底面和图片包围框分离。
- Godot：接入候选后再做headless及横屏截图；当前只交付文档与示意图，不改场景。
- 用户确认单块样板后扩展全营地；远山、溪流、其它建筑和动效属于后续批次。
