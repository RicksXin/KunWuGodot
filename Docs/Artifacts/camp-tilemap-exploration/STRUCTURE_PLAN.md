## 投影与尺度

- 草图试用俯角35°、平面旋转15°，这是用于检视体量的提议，不是从旧图片测出的参数。
- 平行投影：屏幕X = cos(15°)X − sin(15°)Y；屏幕Y = sin(35°)[sin(15°)X + cos(15°)Y] − cos(35°)Z。
- 同尺寸不随远近缩小，所有台地和体块使用相同投影。没有消失点；不是强制2:1等距菱形。
- 草图单位为规划单位，不是Godot像素。+80/+40/0表示三层设计标高，非正式碰撞或楼层数据。
- 地面网格可比较32/48/64，改变网格不会改变建筑体量；默认48只用于比较，不冻结资源尺寸。
- 正式目标视口817×375，最终镜头倍率与横向可滚范围须在结构确认后校准。当前交互图为全局总览，不冒充实际视口截图。
