# 连续岩壁转角样片接入

## 入口

设置 → 营地 TileMap 实验 → 顶部下拉“连续岩壁转角样片”。Godot编辑器打开 scenes/prototypes/camp_terrain_sample.tscn，F6后选择同一条目。命令行可加 -- --corner-preview --no-profile-write --ignore-config-cache。

样片支持拖动、滚轮1×/2×最近邻缩放、占格及48高差对照。此模式关闭地面绘制；开启“增高接台阶”后，可点击台地顶面或下层落脚点，黄色标记经台阶行走。其他实验仍可正常切回。

## 衔接结论

- 连续顶面、内凹与两端外凸的外观已在Godot实际比例复核，截图 corner-sample-ingame.png。
- 原图前端Alpha最下约194，结构顶角160，可见厚度约34；现有台地高差48，两者约差14，包含不规则碎石边，不能当作精密尺寸。
- 蓝线显示结构顶沿下移48的位置，黄色为结构顶沿。新增默认关闭的“增高接台阶”试接：岩壁中段按结构切线插入14个原生像素行、崖脚下移14，顶面不变；复用程序台阶8级×6高差。保持正式高差48，未拉伸整图。该增高结果是临时候选，岩层重复仍需美术验收。
