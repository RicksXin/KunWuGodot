# 营地石铺地样板

入口：营地设置 → 营地 TileMap 实验；或双击根目录 `run_camp_tilemap_lab.command`。
独立场景：`scenes/prototypes/camp_terrain_sample.tscn`。原占位实验文件保留。

- 横版1280×720独立视口，退出恢复原视口、桌面窗口和存档写入保护状态。
- 本样板采用已确认图集的2:1等角投影；不把此前35°/15°试制参数强套在已投影纹理上。正式营地结构与Map01未迁移。
- 地面是原生TileMapLayer，128×64菱形瓦片，nearest过滤。数据为独立四角布尔格，绘制只更新邻接四格；没有从图片生成碰撞。
- 默认议事殿前庭；选择器可切换实心块、横向/纵向窄路、L角、凹角、单格、单格孔洞、两种对角。
- “浏览拖动”移动视图；“铺石地”“擦为泥土”修改地形；复位恢复当前样板。所有修改仅当前会话有效。
- 议事殿已替换为用户批准的GPT带牌匾建筑，透明PNG，开关可隐藏；阻挡仍由独立数据控制。

验证：Godot 4.7.1导入和场景加载通过；`tools/validate_camp_terrain_sample.gd`验证全部16连接状态、10布局、坐标往返、增量修改/擦除、越界拒绝和退出恢复。16张图块Alpha轮廓完全一致。实际渲染前庭截图已检查。

仍需美术工作：台阶/崖壁与后续台地；当前通过的是地面样板，不是完整三层营地。没有新增Meowa调用。

## 台地行走扩展

默认进入“台地行走小样”，两层连续地基、高差48、8级实心石阶、独立可走拓扑、议事殿占地阻挡、点选高亮与上下阶行走已接通。原10个平面布局保留。详细结构、操作、测试与美术替换清单见 `TERRACE_ART_HANDOFF.md`。

台地底部新增“台基：灰盒 / 砌石 / 岩坡”对比菜单；两种本地美术候选尚待视觉批准。岩坡模式保留前庭砌石墙，外侧使用岩层。

顶部下拉新增“全营地结构预览”：七建筑、四阶、传送阵、溪流占位，操作与验收见FULL_CAMP_HANDOFF.md。
