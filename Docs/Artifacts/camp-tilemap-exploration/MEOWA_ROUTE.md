# Meowa 地块集接入评估

依据：用户提供的两张网页截图；本地game-assets技能的maps-tiles-and-textures说明；项目Meowa_API调用规范。
网页链接的公开抓取未返回项目画布内容，本轮没有操作账户或提交生成；不据此声称核验了当前价格、模板详情和下载格式。

## 两种模式的分工

- 截图1：地图生成→等角→地块集→等角Dual-grid，前景/后景纹理用于地面材质过渡。首选验证“石铺路覆盖岩土地面”；后续再做苔藓、湿土与岸线。界面前景/后景指两种地表材质，不是整幅营地的远景与建筑前景。
- 截图2：地图生成→等角→地块，小型地块示例把立面底座和物件合成。可评估岩壁或平台模块，但不能推断会自动得到可拆分建筑、动画、精确阶梯接口或全套高差衔接。
- 旧项目风车编译器接收固定正俯视1024母图；Meowa等角Dual-grid输出属于另一个契约，不能直接混用。

## 视角与尺寸门槛

本地Meowa技能说明其等角纹理为2:1菱形，标准像素等角地块使用128×64逻辑底面，两轴中心步进(64,32)/(-64,32)。这不能直接套用到所有网页模板，仍需实际模板或原始样本验证。
此前样板使用35°俯角/15°平面旋转、48规划单位；轴向和两侧对称性与标准2:1等角不同。不能通过改图片宽高硬凑、也不能用长提示词覆盖固定模板投影。
建议优先以Meowa样本验证模板，再决定是否统一改用2:1投影；用户已确认的连续山体和三层台地结构可保留。当前不擅自把试制数据改为新投影。

## 首次验证建议

1. 查看或下载一个平台自带等角地表原始样本，确认投影、透明边、尺寸、锚点与接缝。只读参考不是生成成果。
2. 确定底材为灰褐岩土、覆材为灰褐风化石路；先从纹理库找合适材质，缺少再单独制作。
3. 仅对一组材质过渡做地块集测试，提示词简洁说明前后关系，避免粘贴旧ChatGPT完整场景/材质母图长提示词。
4. 下载原始图集后核验布局/掩码，再测试实心、走廊、L角、凹角、单格、单格洞与对角连接；确认后制作Godot专用映射。
5. 岩壁/石阶/建筑继续分开制作。不能用一组材质过渡集取代整个营地的立体构件。
