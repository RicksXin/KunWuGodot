# 营地建筑／中景／远景 · 外部生成包

本次共 **11项候选：6座建筑、3片中景、远山与天空各1张**。议事殿复用已确认版本，传送阵先复用现有版本，不重复生成。这里没有提交任何生成或消耗积分。

## 你怎么做
1. 每个编号文件夹是一项任务，打开其中的 `提示词.md`。
2. 按它列出的顺序上传同文件夹里的图片，复制完整提示词。每项开一个独立对话，避免上一建筑污染下一建筑。
3. 每项先生成1张，下载原始PNG，用编号命名（例如 `B01.png`）。建议顺序 B01～B06 → M01～M03 → E01～E02；提示词已全部备齐，不用逐项回来问我。
4. 把原始结果放进 `返回素材` 文件夹后整包交回。全部做好或先返回一部分都可以。不要自行裁切、去底、缩放或镜像。

## 图层和接入边界
从后往前：天空 → 远山 → 后侧中景 → 左右翼中景 → 当前地形 → 建筑和角色 → UI。
中景全部放在可走区域之外，不能覆盖四处台阶和七个门口；右岸水面另作运行时层。本包不是替换可走地形的整图方案。
建筑以现有议事殿的斜俯视正交视角为准，旧建筑只供造型参考。每座2×2占地是工程适配目标，不相信生成器精确输出坐标；实际尺寸、入口锚点、碰撞均在返回后校验，必要时修正候选。
远山和中景是可独立移动的图层。视差幅度将在实机里调，不让模型烘焙移动、雾、粒子、炉火和UI。天空允许静态薄云；独立运动云雾不属本批。

## 返回后由我完成
检查原图尺寸/Alpha与视角 → 制作同比例预览 → 候选场景接入 → 建筑门口和遮挡、相机边界与视差验证 → 一次整体视觉复核。未通过用户视觉确认的图不会覆盖Approved或正式营地。

## 复用审计与限制
`参考总览/现有素材审计.png` 展示已有资产。六座旧建筑多数偏正面且携带较大基座，不能直接算作本次视角合格；已有整背景将地面、山景和天空烘焙到一起，不宜作为新的独立视差层。它们仍可作为造型/色盘参考。
`参考总览/分层位置示意.png` 只是新的分层布局建议，不是已完成美术或用户批准的最终构图。当前地形仍是预览，本次先集中建筑与景深，不继续扩大地形修改。
生成尺寸是建议母图尺寸，不是要求模型像素级遵循。外部平台是否支持透明PNG由实际结果检验；不要用棋盘格或绿幕伪装Alpha。
