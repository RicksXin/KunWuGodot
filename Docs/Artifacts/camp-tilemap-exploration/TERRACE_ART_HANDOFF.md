# 台地小样美术替换规格

当前入口：设置 → 营地 TileMap 实验，默认“台地行走小样”。原10个平面测试仍在下拉菜单。

## 已验证结构

- 6×6逻辑地块；正交投影轴(64,32)、(-64,32)，地块128×64。
- 上层为第0–2行，高差48；下层为第3–5行。石阶占(2,3)，连接(2,2)与(2,4)。石阶内显示高度连续插值。
- 建筑占(1,0)、(2,0)、(1,1)、(2,1)，门前可达点(2,2)，出生点(2,5)。32个可走格连通。
- 本小样使用48高差，替代早期试制40；只适用当前小样，不自动重定整个营地比例。
- 建筑与角色按脚底Y排序。隐藏建筑只便于观察，仍保留其占地阻挡。
- 地形、阻挡独立于图片；台地小样锁定编辑，以避免绘制改变地形却不更新通行规则。平面测试可继续编辑。

## 独立挂点

`CouncilHall/DoorAnchor`：门口互动/提示。
`CouncilHall/SmokeAnchor`：后续烟雾，本轮仅空挂点。
`CouncilHall/LightAnchor`：当前本地灯光脉动，可关闭；换美术后保持独立。

## 操作与验证

“前往门前”“返回下层”验证双向上下阶；“点击行走”点地面寻路，点建筑切换高亮；“浏览拖动”可移动视图，单击也可选目的地。行走过程中不接受新目的地，避免中途重新规划产生跳位。复位恢复出生点并清除路线与选中状态。

验证脚本：`tools/validate_camp_terrace.gd`。覆盖32格可达性、建筑阻挡、崖边拒绝、石阶两侧拒绝横穿、上下阶连续移动、点击高亮、Y排序、挂点与灯光、复位。已检查默认、阶梯中段和建筑背后三张实机截图。

当前是结构小样，不是完整三层营地，也没有接入正式营地角色系统或业务建筑功能。下一阶段替换灰盒美术时如需Meowa生成，须另列单次数量和积分上限。

## 议事殿接入结果

源图：`art/candidates/camp-council-isometric/gpt-v2-plaque/council.png`。保留批准图RGB，使用gpt-v3-alpha的透明轮廓；`tools/prepare_camp_council.py`可复现缩放与留边。运行资源与来源记录在`assets/prototypes/camp_council/`。DoorAnchor=(-83,-31)、LightAnchor=(-111,-50)、SmokeAnchor=(0,-190)，均相对建筑前角。小尺寸牌匾可见但可读性有限。已通过Godot导入、两套验证和默认/阶梯/背后三张实机检查；最终摆放效果待用户复核。本轮Meowa支出0。

## 可切换台基候选

在台地小样下方下拉菜单选择“台基：灰盒 / 砌石 / 岩坡”，默认灰盒。岩坡组合保留前庭挡墙和石阶，外侧换不规则岩层、土壤边和少量苔痕。实现：`scripts/prototypes/camp_stonework.gd`，按既有几何本地确定性绘制，无积分调用。当前仍属几何风格候选，未做高清岩石清稿。

高差、连接、阻挡保持。Godot验证包含三种样式反复切换、唯一楼梯与角色图层顺序，以及32格可达、连续上下阶、16mask/10布局。预览截图：`stonework-preview.png`、`rockwork-preview.png`。两种新台基风格待用户视觉复核；命令行可用`--stonework-preview`或`--rockwork-preview`直接选择。
