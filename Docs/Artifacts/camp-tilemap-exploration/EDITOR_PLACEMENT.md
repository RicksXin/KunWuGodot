# 在 Godot 中摆放营地建筑

最直接入口：双击项目根目录 `run_camp_layout_editor.command`。它打开可保存的摆放工具。`run_camp_tilemap_lab.command` 是游戏预览，不是摆放工具。

1. 打开本项目，点击编辑器顶部与「2D / 3D / 脚本」并列的 **营地摆放**。
   若当前已经打开的编辑器尚未显示：先保存自己的场景，再重新打开项目；也可以在
   **项目 → 项目设置 → 插件** 中启用「营地建筑摆放」。
2. 左键点选建筑并拖动，松开时按 128×64 菱形格吸附。下拉框也能选建筑。
   上方「格 X / Y」可精确移动；门口、接近格和占地同步平移。
3. 「＋ / － / 100%」、滚轮或触控板捏合缩放（10%～600%）；双指滑动或中键/右键拖动平移；「适应地图」恢复全景。
4. 橙框表示所选建筑占地，绿点表示门口，绿线表示接近方向；蓝格是保留院路。
   可开启「半透明建筑」检查地面关系。隐藏建筑也保留导航占地，能从下拉框选中。
5. 「显示宽」调整等比大小，不改变占地尺寸，也不会重新生成建筑朝向。
6. 修改后点击面板自己的 **保存 JSON**。编辑器的场景保存/Ctrl+S 不代替这个按钮。
   重叠、越界、跨高差、堵阶梯、堵院路、堵门口或切断通路时只显示提示，仍然允许保存。位置不再受地形限制；无可达入口的建筑仍显示，但无法走到，点击时会提示。
   如果另一任务改过磁盘 JSON，保存会拒绝覆盖；先记录自己的调整，再重新读取。
7. 「撤销」可以回退本次编辑；「重新读取」会询问是否放弃尚未保存的改动。
   关闭编辑器或禁用插件前请保存，未保存的摆放只在内存中。
8. 保存后重新运行 `run_camp_tilemap_lab.command` 查看真实行走与遮挡；已经运行中的实验不会热更新。

## 自定义贴图旋转

选中建筑后，在「贴图旋转（°）」输入 -360～360 度，精度0.1°；支持 ±1° 微调、归零和撤销。点击「保存 JSON」写回，重新运行实验生效。旋转围绕当前门口图像锚点，只影响二维贴图；占地、门口与寻路不会随贴图旋转，也不会生成新的建筑侧面。已有镜像与招贤馆正背视角可组合使用。

## 数据与限制

- 唯一写回文件：`data/prototypes/camp_tile_rebuild.json`。未操作保存时不会修改文件。
- 插件：`addons/camp_layout_editor/`。不修改正式营地、Map01、玩家存档或生成素材。
- 可编辑位置、大小和「水平翻转」；招贤馆额外提供已有的正面/背面视角切换，并保留图像底座位置。其他建筑目前只有一个视角，可以左右翻转；完整背面需要新增视角素材。切换图像不会伪造新的行走格，门口坐标仍可在后续精调。
- 地形图是从真实实验渲染出来的编辑器专用透明预览，运行游戏仍使用原生TileMap。它不负责寻路，也不被正式游戏读取。未来修改地形后需刷新预览：

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path . \
  --script res://tools/capture_camp_editor_ground.gd \
  -- --no-profile-write --ignore-config-cache
```

生成后让 Godot 完成图片导入，再重新打开摆放插件。此命令不会改变建筑布局。

## 验证

- `tools/validate_camp_layout_editor.gd`：平移同步、地形提示/自由摆放可保存、撤销、临时文件写回、并发修改保护；不写真实布局。
- `tools/preview_camp_layout_editor.gd`：实际面板渲染、鼠标按下/移动/松开、吸附、地形外拖动可保存、捏合缩放、左右翻转/正背切换、撤销；不写真实布局。
- `tools/validate_camp_tile_rebuild.gd`：现有运行导航回归。
