# Map01 俯视整图方案总结

状态：正式运行方案  
地图：`map_01`「破禁山麓·万修之门」

## 1. 最终方案

Map01 使用一张经过视觉批准的高清俯视整图作为纯视觉背景。地图可走区、阻挡、对象坐标、交互、
遭遇和状态不写入背景图片，继续由正式 JSON 与 Godot 运行时 Overlay 独立表达。

```text
高清整图背景
→ 淡纹逻辑网格、迷雾和困难地形提示
→ 正式对象与通用 Marker
→ 玩家、选中、锁定和交互状态
```

该方案不使用 TileMap、Dual Grid、15-piece TileSet、分层山体组件或第二套 Map01 场景。

## 3. 固定规格

- 地图边界：`28×64`。
- 逻辑格：`48×48`。
- 高清背景：`1344×3072`。
- 入口：`(13,6)`。
- 基础可走格：`834`；阻挡格：`958`。
- 正式对象：`31`；地图战斗 Marker：`13`；遭遇：`14`；动态阻挡：`7`。
- 领域坐标 Y 向上，JSON 行向下，换算为 `row_index = 63 - y`。

## 4. 编辑边界

- 背景只负责美术，不从背景像素反推碰撞或对象坐标。
- 基础可走、困难和阻挡只编辑 `terrainRows`；状态碰撞只编辑 `dynamicBlockers`。
- 对象坐标、奖励和交互只编辑 `objects`；遭遇规则编辑正式战斗配置。
- 拖动、缩放、迷雾、网格、Marker 和玩家位置由共用地图运行层表达。
- 未来替换图片时，候选先在项目外或 `art/candidates/` 临时验收；批准后只晋升唯一正式文件，随即删除候选、Demo、Preview 和生成过程素材。

## 5. 已废弃且不得恢复

- 旧 TileMap、Dual Grid 和 15-piece 地形方案。
- V1.3 分层图、山体覆盖组件和方案编号场景。
- 等距注册线、灰盒编辑 Demo、评审场景与预览图。
- 副本入口、出生点、跨图出口的高清建筑式 Marker 候选。
- 低饱和通用小传送阵 Marker 候选。

本文件只总结最终运行结构和维护边界，不保留生成提示词、制作中间图或候选版本。
